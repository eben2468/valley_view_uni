INSTALLATION STEPS (3 MINUTES):
================================================================================

STEP 1: RUN THE INSTALLER
--------------------------
Open your web browser and navigate to:
http://your-website.com/install_new_administration_offices.php

The installer will automatically:
→ Create database records for all 4 pages
→ Set up content sections
→ Populate default content
→ Display success confirmation

STEP 2: VERIFY PAGES
--------------------
Visit each new page to confirm they're working:
→ http://your-website.com/office_of_the_cfo.php
→ http://your-website.com/office_of_rdir.php
→ http://your-website.com/office_of_dsls.php
→ http://your-website.com/office_of_sls.php

STEP 3: CUSTOMIZE CONTENT
--------------------------
1. Log into admin panel: http://your-website.com/admin/
2. Go to "Manage Administration Pages"
3. Click "Edit Content" for each new page
4. Update:
   - Profile images (replace placeholders)
   - Names and titles
   - Biography text
   - Contact information
   - All other content fields

================================================================================
ADMIN PANEL ACCESS:
================================================================================

Location: admin/manage_administration_pages.php

The new pages will appear in the list with:
- Page name
- Number of sections
- Number of editable fields
- Edit and View buttons

Click "Edit Content" to modify any page content through the WYSIWYG editor.

================================================================================
TROUBLESHOOTING:
================================================================================

If pages don't display:
→ Check database connection in includes/db_connect.php
→ Verify all tables exist in your database
→ Clear browser cache
→ Check file permissions

If content doesn't update:
→ Verify admin login credentials
→ Check database write permissions
→ Review PHP error logs
