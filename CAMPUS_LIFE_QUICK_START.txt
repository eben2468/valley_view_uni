INSTALLATION STEPS:
-------------------

STEP 1: Run the Installation Script
   → Open browser: http://localhost/valley_view_uni/install_campus_life_cms.php
   → Wait for "Installation Complete!" message
   → Click "Go to Admin Panel"

STEP 2: Access Admin Panel
   → URL: http://localhost/valley_view_uni/admin/manage_campus_life_pages.php
   → Or click "Campus Life Pages" in the admin sidebar

STEP 3: Edit Content
   → Click tabs to switch between pages
   → Fill in form fields with your content
   → Click "Update Content" to save
   → Click "Preview Page" to view live

TROUBLESHOOTING:
----------------

Problem: "No content found" message
Solution: Run install_campus_life_cms.php

Problem: Changes not showing
Solution: Clear browser cache, check database

Problem: Images not displaying
Solution: Verify image paths and file existence

Problem: Form not submitting
Solution: Check PHP error logs, verify database connection
