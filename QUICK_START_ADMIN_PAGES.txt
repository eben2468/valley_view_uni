═══════════════════════════════════════════════════════════════════════════════
  INSTALLATION (Choose One Method)
═══════════════════════════════════════════════════════════════════════════════

METHOD 1: Automated Installer (RECOMMENDED)
───────────────────────────────────────────
1. Open browser: http://localhost/valley_view_uni/install_administration_cms.php
2. Click "Install Schema & VC Data"
3. Click "Install Pages Data"
4. Done! System is ready to use

METHOD 2: Manual Installation
──────────────────────────────
1. Open phpMyAdmin
2. Select database: valley_view_uni
3. Go to Import tab
4. Import: administration_pages_schema.sql
5. Import: administration_pages_data.sql
6. Done!

  HOW TO USE

STEP 1: Access Admin Dashboard
───────────────────────────────
URL: http://localhost/valley_view_uni/admin/

STEP 2: Edit Content
────────────────────

2. Modify text, change images, update information
3. Click "Save All Changes"
4. Click "Preview" to see changes live

STEP 3: View Changes on Frontend
─────────────────────────────────
Navigate to any of the 5 pages:
- office_of_the_vice_chancellor.php
- office_of_the_pro-vice_chancellor.php
- office_of_the_registrar.php
- rectors.php
- recorders.php

Changes appear immediately!

═══════════════════════════════════════════════════════════════════════════════
  DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

3 NEW TABLES CREATED:

1. administration_pages
   - Stores page metadata (id, slug, title)
   - 5 records (one per page)

2. administration_content
   - Stores content sections (hero, profile, etc.)
   - Multiple sections per page

3. administration_content_fields
   - Stores individual field values
   - Links to content sections
   - Contains actual text/images/URLs

Scenario: Update Vice-Chancellor's email address

1. Go to: admin/manage_administration_pages.php

3. Scroll to "Contact Section"
4. Find "Email" field
5. Change from: vc@vvu.edu.gh

6. Click "Save All Changes"
7. Visit: office_of_the_vice_chancellor.php
8. Email is updated instantly! ✓

No code editing required!

  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Admin page shows "No pages found"
Solution: Run SQL files or installer

Problem: Changes not showing on frontend
Solution: Clear browser cache (Ctrl+F5)

Problem: Images not displaying
Solution: Check image URLs are complete with http:// or https://

Problem: Database connection error
Solution: Check includes/db_connect.php settings
