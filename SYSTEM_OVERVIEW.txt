HOW IT WORKS
═════════════════════════════════════════════════════════════════════════════

1. ADMIN EDITS CONTENT
   └─ Login → Manage Homepage → Edit any section → Save

2. DATA SAVED TO DATABASE
   └─ Content stored in MySQL tables

3. HOMEPAGE FETCHES DATA
   └─ index.php queries database on every page load

4. DYNAMIC DISPLAY
   └─ Content rendered from database, not hardcoded

5. INSTANT UPDATES
   └─ Changes visible immediately on page refresh
