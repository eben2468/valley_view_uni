Valley View Radio — show logos
==============================

Drop show artwork in this folder. The page picks a file up automatically when
its path is set on the show in the admin panel
(Admin > Campus Life > Manage Lists > Radio > Radio Programs > Logo).

Filenames the installer already points at:

    morning-in-the-valley.png   -> "Morning Show"
    campuzvibe.png              -> "CampuzVibe"
    the-business-show.png       -> "The Business Show"

Until a file is actually present, that show's card falls back to its coloured
icon tile — nothing breaks, it just looks plainer.

Guidance
--------
* PNG with a transparent or white background.
* Roughly 800 x 500 px, landscape. The card area is 16:10 and the logo is
  letterboxed inside it, so square logos work too.
* Keep files under ~300 KB.
