================================================================================
HOW IT WORKS
================================================================================

UPLOAD PROCESS:
1. User selects image file
2. Form submits with enctype="multipart/form-data"
3. PHP processes upload
4. Validates file type and size
5. Generates unique filename
6. Moves file to uploads/campus_life/
7. Saves path to database
8. Displays success message

FILE NAMING:
Format: {prefix}_{unique_id}_{original_name}
Example: hero_65d4f2a1b3c4e_campus-photo.jpg

STORAGE:
Location: uploads/campus_life/
Permissions: 755
Access: Web-accessible

4. Find image field (e.g., "Hero Image")
5. Choose one method:

   - Click "Choose File" button
   - Select image from computer
   - Click "Update Content"
   
   METHOD B - Enter Path Manually:
   - Type image path in text field
   - Example: uploads/campus_life/my-image.jpg
   - Click "Update Content"

6. Image preview displays below field
7. Success message confirms upload

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Upload fails
SOLUTION: 
- Check file size (under 5MB)
- Verify file type (JPG, PNG, GIF, WebP)
- Ensure directory exists
- Check folder permissions

PROBLEM: Image doesn't display
SOLUTION:
- Clear browser cache
- Verify file path
- Check file exists
- Verify permissions

PROBLEM: Manual path not working
SOLUTION:
- Use relative paths
- Start from project root
- Example: uploads/campus_life/image.jpg
- No leading slash
